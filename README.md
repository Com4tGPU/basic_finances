# basic_finances
THIS IS NOT AN ACTUAL BANKING APP AND SHOULD NOT BE USED AS FINANCIAL ADVICE! Program that lets you add a balance, add or task away from it, and use a calculator.

## the features

 - PIN protected (change your pin via changing variable pass)
 - Built in Calculator
 - Keep track of your balance
 - add or subtract from balance

## how to change PIN

1. go to file
2. go to line 75
3. Should say " double pass(3322); "
4. change 3322 to anything you want.
